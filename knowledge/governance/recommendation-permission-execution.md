# Recommendation, Permission, and Execution

A recommendation proposes a next step. Permission establishes whether that step may occur. Execution performs it. These stages require separate evidence, governance, and audit records.

An agent recommendation is never approval, and approval may still be insufficient for execution when dependencies or policy conditions remain unresolved.
