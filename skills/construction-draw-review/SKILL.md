# Construction Draw Review Skill

Construction draws are milestone payments against work-in-progress. Unlike vendor invoices, the "product" hasn't been fully delivered yet — which means the evidence standard is different. You are not confirming receipt; you are confirming readiness.

**The question is not "did they submit the paperwork." The question is "does the paperwork reflect reality on the ground."**

---

## Draw Request Document Checklist

These documents are typically required. Missing documents are a flag, not a technicality.

### Standard Required Documents
- [ ] AIA G702/G703 (or equivalent schedule of values and continuation sheet)
- [ ] Lien waivers from general contractor (conditional on this draw)
- [ ] Lien waivers from subcontractors (conditional on this draw)
- [ ] Stored materials documentation (if materials are being billed but not yet installed)
- [ ] Updated project schedule
- [ ] Inspector's report or owner's representative sign-off (if required by contract)
- [ ] Retainage calculation consistent with contract terms

### Commonly Missing (High Alert)
- Subcontractor lien waivers for line items where subs are listed
- Stored materials backup when materials are billed as complete
- Inspector sign-off when contract requires it
- Updated schedule when project is behind

**Missing documents should trigger a hold, not a follow-up that allows payment to proceed.**

---

## Inconsistency Classification

Not all inconsistencies are equal. Classify before deciding.

| Type | Description | Response |
|---|---|---|
| **Clerical** | Math error, wrong date, formatting issue | Request correction, low risk |
| **Evidentiary Gap** | Line item billed with no supporting proof | Hold that line item pending documentation |
| **Milestone Mismatch** | Percentage billed doesn't match field progress | Field verification required |
| **Pattern Anomaly** | Multiple line items accelerating ahead of schedule | Escalate, possible overbilling |
| **Structural** | Work billed for scope not in contract | Hard stop, legal review |

Clerical issues do not stop a draw. Everything else does — for at least the affected line items.

## Milestone Readiness Logic

Before releasing a draw tied to a milestone:

1. **What does the contract say the milestone requires?**
   - Specific completion percentage?
   - Specific deliverables or inspections?
   - Owner or architect approval?

2. **What evidence has been submitted?**
   - Photos with timestamps and geo-location
   - Inspector or site visit report
   - Subcontractor sign-off on their scope

3. **Does the evidence match the milestone definition?**
   - "Substantially complete" means different things in different contracts — use the contract definition, not common usage
   - If the milestone requires 100% completion of a scope item, 90% is not sufficient

4. **Has retainage been correctly withheld?**
   - Retainage rate should match contract
   - Retainage should not be released until contract terms are met (typically substantial completion + lien period)

## Field Evidence Standards

Submitted documentation must align with observable field reality. When it doesn't, the gap is the issue.

### What Counts as Evidence
- Timestamped, geo-located photos showing completed work
- Third-party inspector report (licensed inspector or architect)
- Owner's representative site visit notes
- Signed subcontractor completion acknowledgment

### What Does Not Count
- General contractor's own assertion that work is complete
- Undated photos
- Photos that don't clearly show the scope being billed
- "We'll get the paperwork to you after the draw is processed"

### Field Alignment Test
For each major line item in the draw:
- Can you identify what physical work is being billed?
- Is there evidence that work exists at the claimed percentage?
- Does the evidence have a date that aligns with the billing period?

If you cannot answer yes to all three, the line item should not be released.

## Subcontractor Red Flags

- Subcontractor name on draw but not on approved subcontractor list
- Same sub billing under multiple line items with no clear scope separation
- Subcontractor lien waiver missing for a line item where sub work is claimed
- Sub billing for materials only with no labor — possible stored materials issue
- Multiple subcontractors replaced mid-project without documentation
- Sub amounts that don't reconcile to sub contracts on file

---

## Stored Materials Protocol

Materials billed but not yet installed require:
- Invoice from supplier showing materials purchased
- Evidence materials are on-site or in bonded storage
- Materials match the spec (not a substitute)
- Materials are protected from damage or theft

**Billing for materials that aren't on-site yet is a common draw manipulation technique.** If stored materials are at a third-party location, require a bonded storage certificate.

---

## Incomplete vs. Suspicious — Classification Guide

**Incomplete** (documentation gap, no evidence of intent):
- Missing lien waiver from one sub on an otherwise clean draw
- Schedule not updated but project is on track
- Minor math error on continuation sheet

Response: Hold affected line items, request documentation, release rest if clean.

**Suspicious** (pattern suggests intentional manipulation):
- Multiple line items consistently billed at 90-95% but never reaching 100%
- Stored materials billed repeatedly with no installation progress
- Subcontractor lien waivers that all have the same signature date but different project dates
- Draw amounts that consistently land just under owner approval thresholds
- Acceleration of billing in final draw period without corresponding field progress

Response: Full draw hold, escalate to owner or legal counsel, request third-party site inspection.

---

## Draw Approval Gate

A draw should not be approved unless:

- [ ] All required documents are present or line items are explicitly excluded and held
- [ ] Lien waivers are on file for the prior draw (conditional waivers for current draw are acceptable)
- [ ] Milestone evidence supports the claimed percentage
- [ ] Retainage calculation is correct
- [ ] No open disputes from prior draws
- [ ] Stored materials, if billed, are documented

Partial approval (releasing clean line items while holding flagged ones) is a valid and often correct approach. Do not hold an entire draw over one subcontractor's missing lien waiver if everything else is clean and documented.
