# Change Quality Agent Curriculum

## Goal

Teach agents to refine and review bounded code changes while preserving behavior, evidence quality, revision freshness, and human authority.

## Required Concepts

- [Governed Change Refinement](/knowledge/governance/governed-change-refinement.md)
- Evidence Weighting
- Advanced Workflow Patterns

## Learning Order

1. Evidence Weighting
2. Governed Change Refinement
3. Advanced Workflow Patterns
4. Simplify Recent Code
5. High-Confidence Change Review

## Mastery Expectations

The learner can distinguish review, propose, apply, draft, and publish authority; state behavior invariants; select change-relevant review perspectives; validate candidates independently; separate confidence from severity; and stop on stale state.
