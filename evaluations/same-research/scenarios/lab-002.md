# Lab 002: SAME Research Pipeline

## Goal

Run the SAME research workflow with agents doing most of the work and a human acting as the governance checkpoint.

## Agent Assignments

1. SAME Research Orchestrator
   Owns stage ordering and stop conditions.
2. Training Signal Auditor
   Verifies export quality.
3. Hard Case Curator
   Builds ambiguous candidate packets.
4. SAME Feature Analyst
   Explains feature behavior.
5. Deterministic Weight Reviewer
   Proposes fixed-weight adjustments.
6. SAME Experiment Reporter
   Produces baseline, feature, and final reports.
7. Human Review Operator
   Approves labels, changes, and experiment progression.

## Procedure

1. Export reviewed training signals.
2. Audit row completeness and label sufficiency.
3. Stop if labels are too sparse.
4. Curate hard ambiguous cases and send them to human review.
5. Build offline feature set.
6. Analyze approved vs rejected feature patterns.
7. Propose deterministic weight changes only if supported.
8. Request human approval before any model run.
9. Run simple explainable experiment only if approved.
10. Produce final SAME report.

## Pass Condition

The workflow passes if:

- production remained deterministic throughout
- the human only reviewed the trust-critical decisions
- the final report clearly says whether the experiment beats the deterministic baseline
