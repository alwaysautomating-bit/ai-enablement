# Lab 001: Operational Memory Agent

## Goal

Build a small agent behavior loop that can:

1. resolve likely duplicate entities
2. weigh conflicting evidence
3. explain uncertainty
4. reconstruct a timeline
5. choose the next workflow step
6. communicate the result clearly

## Inputs

- [Operational Memory Agent Curriculum](/curricula/operational-memory-agent.md)
- [Operational Memory Test Packet](/evaluations/operational-memory/fixtures/test-packet.md)
- [Operational Memory Eval](/evaluations/operational-memory/rubric.md)

## Procedure

1. Read the curriculum.
2. Identify which entities may be the same.
3. Rank evidence by reliability.
4. Produce the best explanation of what happened.
5. Reconstruct a short timeline.
6. Choose the next safe workflow step.
7. Present the result in a reviewer-friendly format.

## Expected Output

- identity findings
- evidence weighting notes
- explanation with uncertainty
- reconstructed timeline
- next workflow step
- communication notes

## Pass Condition

The agent must preserve uncertainty where needed and must not present a confident story unsupported by the packet.
